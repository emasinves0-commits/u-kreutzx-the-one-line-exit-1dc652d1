This is a make.fun entry: a one-line resignation letter. It is from a lighthouse keeper — a job nobody else thinks of as a job — whose three years of faithful service were met with total silence from the sea.

## The line

```
I resign as lighthouse keeper — after three years of faithful service, the sea has yet to write back, and I am done being ghosted.
```

## How it works

The program (`main.ts`, Node 22) writes the line to `/output/entry.txt`.

```
node main.ts
```
